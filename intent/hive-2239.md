## Problem (seen on WEB-163, 2026-09-17)

## Fix

- Intake downloads every attachment on import and on each sync when the attachment list changes, into `~/.hive/briefs/attachments/<KEY>/<filename>` (size cap, image/pdf/text only), and writes the LOCAL PATH next to each `[attachment: …]` marker in the mirror brief and the intent body so agents can `Read` them. Skip on auth failure with one logged line; never block the import.
- The intent drafting prompt must be told to (a) treat the full description and comments as the source, (b) answer a question itself when the text answers it and put the answer under `## Constraints`, and (c) only leave a bullet under `## Open questions` when the text genuinely does not say. Add a fixture test using WEB-163's description: expect zero open questions and at least four constraints (matching rule, CMS add/remove, scope deal+dev all sectors, sort 최신순 + dropdown).
- When the ticket references images ("이미지 3", "시안"), the drafter names the local path in Constraints.
